Everything on your screen is 1s and 0s

Information and Communication Technology is how we store, process and send data. Start with the smallest piece: type a word and see the bytes behind it.

Each character is stored as one byte: eight bits, each either 1 or 0. Blue cells are 1.

The six areas of ICT

Almost every ICT job or module sits inside one of these areas.

Hardware

The physical parts of a system: processor, memory, storage, and input and output devices.

Examples: CPU, RAM, SSD, keyboard, monitor

Software

The programs that tell hardware what to do, from the operating system to everyday apps.

Examples: Windows, Linux, web browsers, spreadsheets

Networks

Connected devices that share data and resources, in one room or across the world.

Examples: LAN, Wi-Fi, routers, the internet

Databases

Organised collections of data that can be searched, updated and shared safely.

Examples: MySQL, student records, online shop catalogues

Cybersecurity

Protecting systems and data from theft, damage and unauthorised access.

Examples: strong passwords, firewalls, encryption, backups

Web and cloud

Websites and services that run on remote servers and are used through a browser.

Examples: HTML, web hosting, cloud storage, online email

What happens when you open a website

Five steps happen in under a second.

  1. Your device sends a requestYour browser asks for a page, such as example.com.
  2. DNS finds the addressThe domain name is looked up and turned into an IP address.
  3. The request crosses the networkYour router and internet provider pass the data along, split into small packets.
  4. The server repliesThe web server sends back the HTML, CSS and images for the page.
  5. Your browser draws the pageThe packets are put back together and displayed on your screen.

Glossary

Tap a term to read its meaning.

Bit and byte

A bit is a single 1 or 0. A byte is eight bits and can store one character, such as the letter A.

IP address

A number that identifies a device on a network, like a postal address for data.

Router

A device that sends data between networks and connects your home or office to the internet.

Operating system

The main software that manages hardware and runs other programs, such as Windows, macOS or Android.

Encryption

Scrambling data so only someone with the correct key can read it.

Cloud computing

Using servers on the internet to store data or run software instead of using only your own computer.

Networks

A network is two or more devices connected so they can share data. The internet is millions of networks joined together.

LAN

A local area network covers one place, such as a home, school or office. It is fast and usually owned by one person or organisation.

WAN

A wide area network joins networks across cities or countries. The internet is the largest WAN.

Cybersecurity

Cybersecurity keeps data private, correct and available. Know the common threats and the habits that stop them.

Common threats

Phishing
Fake emails or messages that trick you into giving away passwords or money.
Malware
Harmful software such as viruses and spyware.
Ransomware
Malware that locks your files until you pay.
Brute-force attack
Trying thousands of passwords until one works.

Good defences

Strong passwords and 2FA
Long, unique passwords plus a second check, such as a phone code.
Software updates
Updates fix security holes before attackers use them.
Firewall and antivirus
Block and remove known threats.
Backups
Keep copies of your files so you can recover from loss or ransomware.
